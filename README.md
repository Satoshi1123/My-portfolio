# My-portfolio

## 毎週の更新方法

### 投資メモ

`holdings-data.js` の配列だけを更新します。

- `updatedDate`: 投資メモの基準日
- `realized`: 売却済み銘柄。売却日、銘柄名、数量、売却金額、確定損益を追加
- `current`: 保有中銘柄。銘柄名、種類、数量、取得金額、評価額、評価損益を追加

表の行と合計金額は自動生成されるため、HTMLの表や合計を直接編集する必要はありません。

### ブログ

`blog-data.js` の `blogPosts` 配列の先頭に記事を追加します。

- `date`: `YYYY-MM-DD` 形式の日付
- `title`: 記事タイトル
- `summary`: 記事の概要

新しい記事を配列の先頭に追加すると、ブログ画面でも先頭に表示されます。

### ホームのグラフ

`dashboard-data.js` の `dashboardData` 配列に、毎週1行追加します。

- `date`: `YYYY-MM-DD` 形式の日付
- `profit`: その週の損益
- `breakdown`: `[国内株式, 投資信託, 外国株式]` の順で金額を入力

総資産、前週との差、損益カード、折れ線グラフ、円グラフは自動更新されます。円グラフはグラフ上の週をクリックすると、その週の内訳に切り替わります。

年が変わったら、同じ配列に `2027-01-xx` の形式で追加してください。登録されている年はホームに「2026年」「2027年」のタブとして自動表示され、年ごとに損益と資産内訳を切り替えて確認できます。
